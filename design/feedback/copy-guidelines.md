# Feedback copy

Say what happened, then give the next action if one exists. Place field help beside the affected field. Use the same term as the control. Keep the tone warm and plain. The current FigCraft flows use English. The Indonesian examples below provide an equivalent voice for localization.

| Situation | English | Indonesian |
| --- | --- | --- |
| Required email | Enter your email. | Masukkan alamat email. |
| Invalid email | Enter an email like name@example.com. | Masukkan email dengan format seperti nama@contoh.com. |
| Incorrect credentials | Email or password is incorrect. | Email atau kata sandi kurang tepat. |
| Existing account, where safe to disclose | This email is already in use. Log in to continue. | Email ini sudah digunakan. Masuk untuk melanjutkan. |
| Incorrect OTP | That code doesn’t match. Check it and try again. | Kodenya kurang tepat. Periksa lalu coba lagi. |
| Expired OTP | This code expired. Request a new code. | Kode ini sudah kedaluwarsa. Minta kode baru. |
| Resend confirmed | Code sent. Check your inbox for the latest code. | Kode terkirim. Cek kotak masuk untuk kode terbaru. |
| Reset request accepted | If this address has an account, we’ll send password reset instructions. | Jika email ini terdaftar, kami akan mengirim petunjuk untuk mengatur ulang kata sandi. |
| Offline | Connection lost. Check your internet and try again. | Koneksi terputus. Periksa internetmu dan coba lagi. |
| Retryable timeout | This is taking longer than expected. Try again. | Prosesnya lebih lama dari biasanya. Coba lagi, ya. |
| Write outcome is unknown | We couldn’t confirm that your changes were saved. Check the latest status. | Kami belum bisa memastikan perubahanmu tersimpan. Cek status terbaru. |
| General server error | Something went wrong. Try again in a moment. | Ups, ada kendala. Coba lagi sebentar, ya. |
| Session expired | Your session ended. Log in again to continue. | Sesimu berakhir. Masuk lagi untuk melanjutkan. |
| Destructive confirmation | Delete this task? This removes it from your planner. | Hapus tugas ini? Tugas akan dihapus dari plannermu. |
| Unsaved changes | Discard this draft? The changes you made will be lost. | Buang draf ini? Perubahan yang kamu buat akan hilang. |

Use a direct destination as the confirmation when it already explains the outcome. Avoid echoing a successful destination with another toast. Use distinct outcomes for unavailable data, zero results, and stale cached data. A request may have been accepted without email delivery having been confirmed. Say what the service actually confirmed. Keep internal messages, request identifiers, credentials, OTP values, and personal content out of visible or spoken copy. Avoid revealing account existence where the approved privacy policy gives one response.
