# Alongio hybrid motion usage map

Phase 12B is a DESIGN_ONLY proposal. The six concepts below use the existing Reanimated stack. No new asset or animation package is required. Frame IDs refer to the approved design. Timing uses existing Soft Playful Motion presets or simple multiples of them. Values below are design targets pending device review.

## Technology and trade-offs

| Category | Decision and approved artwork | Complexity, performance, and alternatives |
| --- | --- | --- |
| A01 · App Loading | Reanimated pastel dots inside the existing loading cue. The approved heart icon can supply a still fallback or a future larger treatment. | Low. Three shapes and one shared loop. An external loader or JSON offers little benefit at 14 px. |
| A02 · Task Completion | Reanimated scale and spring on the existing checkbox visual, with one optional approved sparkle in the banner. | Low. One transform plus an optional accent. Reuse the approved [check SVG](../system/assets/icon-check.svg). A third-party check cannot own the checked state or Undo. |
| A03 · Celebration | Reanimated particle burst using token-colored circles, rounded paper strips, and the proportions of existing sparkles. The approved paired art stays still. | Medium. One progress value drives a small fixed pool. A Skia-backed library can render denser effects but adds native dependencies and is unnecessary at this scale. See the [dependency review](../motion/react-native-handoff.md#dependencies-and-build-impact). |
| A04 · Save Success | Reanimated one-shot around the existing bookmark or check, with a decorative heart where it fits. | Low. Animate a small wrapper so the saved state stays visible. Reuse the approved [heart](../system/assets/icon-heart.svg) or [check](../system/assets/icon-check.svg). |
| A05 · Kitchen Loading | Reanimated translation on the existing Kitchen Magic food illustration wrapper. | Low. One visual layer with no vector morph or extra renderer. A downloaded cooking loop duplicates approved artwork and adds a package requirement. |
| A06 · Empty State | Reanimated float on entry, then keep the original illustration still. | Low. Reuse an approved layer such as the [Diary scrapbook](../system/assets/diary-scrapbook.svg) or the FigCraft cookbook pocket. A looping third-party illustration brings little value once the state has settled. |

Reanimated is the free open-source library selected for each of these categories. No effect needs a GitHub Lottie file in the initial rollout.

## Timing and storyboard

The approved source frames supply the resting state, action bounds, and decorative area. The beats below describe authored checkpoints for implementation review. Reanimated worklets, randomized particles, real spring timing, loop seams, runtime performance, and OS Reduce Motion changes are **NOT VERIFIED** in FigCraft.

| Category and reference | Start → middle → end | Trigger, interruption, and reduced motion |
| --- | --- | --- |
| A01 · [FC-1163 Log in · Loading](../handoff/screen-inventory.md#fc-1163) | Three 3 px circles with 2 px gaps fit inside the existing 14 px cue. Each dot rises up to 1 px over 180 ms, returns over 140 ms, and rests for the remainder of a 900 ms cycle. Offset each by 90 ms and keep start/end positions identical. Use approved Pink, Indigo, or neutral accents as contrast permits. | Loop only while the request is pending and the screen is visible. Stop on completion, error, cancellation, or exit. Reduced motion keeps the existing loading text and a static indicator. |
| A02 · [FC-2736 Planner · Task completed](../handoff/screen-inventory.md#fc-2736) | Update the checked state immediately. Bring the inner icon to about 1.08× over the 90 ms press role, then spring back to 1×. Start tuning with mass 1, stiffness 260, and damping 30. Aim for a brief settle and prevent spill outside the icon well. An optional sparkle fades within the 350 × 64 banner. | A single cue follows confirmed completion. Undo cancels any outstanding decoration and updates immediately. The touch target, task row, list offset, and Undo stay in place. Reduced motion shows the checked control and confirmation with no scale motion. |
| A03 · [FC-5388 Level-up celebration](../handoff/screen-inventory.md#fc-5388) · [FC-24808 Connection confirmed](../handoff/screen-inventory.md#fc-24808) | Start near an existing decorative corner, away from copy and controls. Spread 12 shapes within the approved illustration area, capped at 16. Use roughly 20–48 px of travel as space allows and small rotations. Meet the 480 ms budget with an early spread and a fade over the final 140 ms. Use the approved Romantic Pink, Butter Yellow, Soft Indigo, Lavender, and Matcha Green. | One burst per confirmed milestone. The 350 × 304 Level-up panel and smaller connection illustration need separate bounds checks. Keep the paired art, title and CTA unobscured. Cancel on exit. Reduced motion shows the static artwork and milestone copy. |
| A04 · [FC-16203 Saved tomato orzo](../handoff/screen-inventory.md#fc-16203) | Keep the filled bookmark and label visible. Use one small heart or check accent with up to two small sparks. Expand slightly over 180 ms and fade over 140 ms. Keep the footprint within the existing 169 × 48 confirmation. | Play once when save succeeds. Unsave, navigation, or a new operation clears the effect. Reduced motion keeps the filled bookmark and saved label. |
| A05 · [FC-21854 Kitchen Magic loading](../handoff/screen-inventory.md#fc-21854) | Inside the existing 350 × 264 cooking panel, move the approved 168 × 128 food illustration wrapper from its resting position to at most 4 px above, then back. Use an eased 720 ms up and 720 ms down with matching endpoints. Keep the progress copy fixed. | Loop only during recipe generation, with no percentage or apparent completion milestone. Stop on resolve, error, cancellation, or exit. Reduced motion keeps the still illustration and progress copy. |
| A06 · [FC-12623 Empty diary](../handoff/screen-inventory.md#fc-12623) · [FC-16167 Empty saved recipes](../handoff/screen-inventory.md#fc-16167) | Begin at the approved resting position, float at most 4 px over 240 ms, then return over 240 ms. Only the scrapbook or cookbook illustration wrapper moves. Keep card, text, and action fixed. | Play once when a genuine empty state appears. Cancel when content arrives or the screen is left. Reduced motion shows the approved static illustration, explanation, and action. |

Use `motion.easing.enter` for reveals and outward bursts, and `motion.easing.exit` for disappearing accents. Use a symmetric sine ease-in-out for each leg of the dot, kitchen, and empty-state translation. Each leg begins and ends at rest, preserving a smooth turnaround and loop seam. On every path, the state label and action remain available even if the decoration never renders.
