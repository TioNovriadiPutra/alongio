# Alongio screen inventory

Source is the editable [FigCraft master](../Alongio.figcraft). IDs are native FigCraft frame IDs. The screen names and frame tree came from the live MCP snapshot. Links in the inventory point to archived exports. Use the approved responsive master and the phase review boards for current geometry. See the [final regression audit](final-regression-audit.md) for the baseline comparison.

All 308 mobile frames are 390 × 844 and locked. The inventory follows the master page order. Mode labels describe the intended scope or the visible fixture. Access enforcement requires product and implementation verification.

Each exit lists the exact control or timer and native layer ID, with its destination or native history action. Keyboard shortcuts are simulations. A **Backdrop** entry is a recorded action underneath a named scrim. Entry points are foreground predecessors unless labeled otherwise. **Orphan** means no recorded inbound transition and no audit or named start. A dash indicates zero recorded screen actions. See the [navigation map](navigation-map.md) for reachability definitions and duplicate pairs.

Component-only actions live outside the screen frame inventory. The original notification preference control variants switch between native components 25415 and 25423. The approved Profile-local pair uses 37663 and 37671. The component definitions and screen-level routes are separate evidence.
